Privacy policy

Last updated: 21 November 2026

This website

This site is a set of static pages hosted on GitHub Pages. It has no accounts, no forms, no cookies, no analytics and no advertising. GitHub, which hosts the pages, may log technical data such as IP addresses when pages are requested; see the GitHub Privacy Statement.

The ApexCompute publishing tools

ApexCompute uses two small tools to publish its own videos and posts: a self-hosted copy of the open-source scheduler Postiz, and a command-line script. Both run only on the channel owner's own computer and are used only to manage ApexCompute's own accounts. They are not offered to anyone else.

When the owner connects the ApexCompute YouTube channel, the tools use YouTube API Services to:

  • upload ApexCompute's own videos and set their title, description, tags, thumbnail, captions, playlist and publishing time;
  • read back the status of those uploads (for example, whether a scheduled video is now public);
  • read the channel's own playlists and upload list, to avoid uploading the same video twice.

The tools do not read, collect or store data about viewers or any other YouTube users. The access tokens Google issues are stored only on the owner's computer, in files readable only by the owner, and are never shared with or sold to anyone.

By using these tools the channel owner agrees to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time from Google Account → Third-party connections, after which the stored tokens stop working; deleting them from the computer removes them completely.

Other platforms

ApexCompute also posts on Substack, Bluesky, X, Instagram and Facebook. Those platforms have their own privacy policies; ApexCompute does not receive personal data about readers or viewers beyond what each platform shows every account owner.

Changes and contact

If this policy changes, this page will be updated and the date above changed. Questions can be raised by opening an issue in the repository for this site.
