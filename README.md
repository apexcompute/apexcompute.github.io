# apexcompute.github.io

Source of https://apexcompute.github.io: the ApexCompute home page, privacy policy and one page per course.

- `courses/<course>/` holds a course's page and, as episodes are published, its notes and code. Each course folder carries its own license notes where it uses upstream material.
- Plain HTML and one stylesheet; no build step. Videos and large result files are not kept here.
